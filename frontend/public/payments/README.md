# Marcas de pagamento

Assets originais, sem redesenho, servidos localmente apenas para identificar os meios de pagamento. Direitos de marca permanecem com os titulares. Fonte consultada em 24/10/2026.

- `mercadopago.svg`: símbolo servido pela própria documentação Mercado Pago Orders, em https://http2.mlstatic.com/frontend-assets/dx-template-lib/assets/logo-mercadopago.svg. Página de origem: https://www.mercadopago.com.br/developers/pt/docs/checkout-api-orders/overview. Orientações de marca: https://www.mercadopago.com.br/mp/logo-oficial.
- `pix.svg`: símbolo monocromático original disponibilizado pela participante Cielo em https://www.cielo.com.br/assets_cielo/contrato/icons/pix.svg. Manual oficial Pix: https://www.bcb.gov.br/content/estabilidadefinanceira/pix/Regulamento_Pix/I_manual_uso_marca_pix.pdf, versão 1.6, especialmente paridade entre instrumentos de pagamento. Sem recoloração/filtros, com base branca e espaço de proteção.

Os SVGs não contêm scripts, eventos, referências de rede ou fontes externas. Os textos adjacentes são os nomes acessíveis; as imagens são decorativas e não determinam autorização, disponibilidade ou confirmação de pagamento.
