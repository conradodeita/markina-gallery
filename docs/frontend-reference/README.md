# Referências de frontend — Markina Gallery

## Fonte oficial de decisão

O protótipo em `stitch-export/` é uma referência visual e funcional, não a arquitetura da aplicação. O Claude Code deve reconstruir o frontend conforme `DIRETRIZES_FRONTEND_MARKINA_GALLERY.md`, a especificação do executor, o roadmap e as specs OpenSpec vigentes.

É proibido copiar diretamente o código exportado, seus mocks, URLs, dados, dependências ou decisões de infraestrutura.

## Pastas

- `stitch-export/`: referência atual aprovada;
- `stitch-export-v1/`: versão anterior, mantida apenas para comparação.

## Ordem de prioridade

1. requisitos de produto e segurança;
2. `INSTRUCOES_EXECUTOR_CLAUDE_CODE.md`;
3. `ROADMAP_ARQUITETURA.md`;
4. `DIRETRIZES_FRONTEND_MARKINA_GALLERY.md`;
5. specs OpenSpec implementadas;
6. protótipo do Stitch, apenas para decisões visuais ainda não especificadas.
