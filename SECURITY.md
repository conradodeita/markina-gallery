# Política de segurança

Não abra issues públicas para vulnerabilidades, credenciais expostas, acesso indevido, dados pessoais ou mídia privada.

Use o [reporte privado de vulnerabilidades do GitHub](https://github.com/conradodeita/markina-gallery/security/advisories/new). Inclua uma descrição mínima, passos de reprodução com dados sintéticos, impacto potencial e uma forma segura de acompanhamento. Não inclua segredos, arquivos `.env`, tokens, chaves privadas, dumps de banco ou fotos de clientes.

O mantenedor confirmará o recebimento, avaliará o impacto e coordenará a correção de forma privada. Nenhuma pessoa que reportar uma vulnerabilidade deve executar testes contra produção, acessar dados de terceiros ou publicar detalhes antes da correção acordada.
