- Se a validação falhar antes da promoção, os candidatos ficam fora do tráfego. Se falhar durante ou após a troca, registrar o motivo, repetir o inventário e usar o retorno manual previamente aprovado para reativar somente os containers anteriores da API e da web e restaurar os aliases. Recarregar o Nginx da Markina e repetir os mesmos smokes. Nenhum downgrade de schema ou restauro de dados integra este plano.

- Após publicação validada, o proprietário reautentica em Plataforma e o fluxo chega ao consentimento Google. A revisão e a aprovação do escopo `drive.file` pertencem ao proprietário.
